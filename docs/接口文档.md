# 海外藏中国文物知识管理与服务平台后台子系统接口文档

## 1. 文档说明

本文档根据当前项目后端代码整理，适用于后台管理子系统的接口联调、验收展示和后续维护。

- 后端项目：`backend`
- 前端项目：`frontend`
- 后端框架：Spring Boot 3.5.14、MyBatis-Plus、MySQL
- 默认服务地址：`http://localhost:8080`
- 接口统一前缀：`/api/admin`
- 请求数据格式：`application/json`
- 字符编码：`UTF-8`

## 2. 运行与联调地址

### 2.1 后端服务

后端启动成功后，控制台应显示 Tomcat 已在 8080 端口启动。

```text
Tomcat started on port 8080
Started BackendApplication
```

如果 8080 端口被占用，可以关闭占用进程，或临时修改 `backend/src/main/resources/application.yml` 中的端口。

### 2.2 前端页面

前端为静态页面，入口文件为：

```text
frontend/index.html
```

建议在 `frontend` 目录下启动本地静态服务：

```powershell
python -m http.server 5173 --bind 127.0.0.1
```

浏览器访问：

```text
http://127.0.0.1:5173
```

前端默认请求后端地址：

```text
http://localhost:8080/api/admin
```

## 3. 统一响应格式

所有接口统一返回 `Result<T>` 结构。

### 3.1 成功响应

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {}
}
```

### 3.2 失败响应

```json
{
  "code": 401,
  "message": "请先登录",
  "data": null
}
```

常见失败码：

| code | 说明 |
| --- | --- |
| 401 | 未登录、Token 缺失、Token 过期或无效 |
| 403 | 已登录但身份类型不匹配，或账号已被禁用 |
| 500 | 业务校验失败或系统异常 |

### 3.3 分页响应

分页接口的 `data` 字段为 `PageResult<T>`。

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "records": [],
    "total": 0,
    "pageNum": 1,
    "pageSize": 10
  }
}
```

## 4. 测试账号

系统初始化脚本内置 3 个后台账号，均可用于登录测试。

| 用户名 | 密码 | 角色 | 说明 |
| --- | --- | --- | --- |
| `admin` | `123456` | 超级管理员 | 拥有全部权限 |
| `reviewer` | `123456` | 内容审核员 | 主要用于内容审核 |
| `dataadmin` | `123456` | 数据管理员 | 主要用于文物数据维护 |

当前后端已实现 JWT 登录鉴权。除 `/api/admin/auth/login` 外，后台管理接口都需要携带后台管理员 Token。

请求头格式：

```text
Authorization: Bearer 登录接口返回的token
```

身份类型区分：

| 接口前缀 | 要求身份 | 说明 |
| --- | --- | --- |
| `/api/admin/**` | `ADMIN` | 后台管理员接口，只允许后台管理员 Token 访问 |
| `/api/user/**` | `PLATFORM_USER` | 预留给其它子系统的平台用户接口，只允许平台用户 Token 访问 |

这样后台管理员和平台普通用户不会混用同一类接口。

## 6. 登录认证模块

### 6.1 后台登录

- 请求方式：`POST`
- 请求地址：`/api/admin/auth/login`

请求体：

```json
{
  "username": "admin",
  "password": "123456"
}
```

返回数据：登录令牌和后台管理员信息。

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "token": "eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9...",
    "tokenType": "Bearer",
    "userType": "ADMIN",
    "expireAt": "2026-05-29T23:59:59",
    "adminUser": {
      "id": 1,
      "username": "admin",
      "realName": "系统管理员",
      "roleId": 1,
      "roleName": "超级管理员",
      "status": 1
    }
  }
}
```

说明：

- 用户名不存在时返回登录失败。
- 密码不正确时返回登录失败。
- 账号状态为禁用时返回登录失败。
- 登录成功后返回 8 小时有效的 JWT Token。
- 前端会自动把 Token 放入后续请求头。

### 6.2 获取当前管理员信息

- 请求方式：`GET`
- 请求地址：`/api/admin/auth/profile`

请求头：

```text
Authorization: Bearer 登录接口返回的token
```

返回数据：根据当前 Token 解析出的后台管理员信息。

## 8. 文物数据管理模块

### 8.1 分页查询文物

- 请求方式：`GET`
- 请求地址：`/api/admin/artifacts/page`

查询参数：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `pageNum` | Long | 否 | 页码，默认 1 |
| `pageSize` | Long | 否 | 每页数量，默认 10 |
| `title` | String | 否 | 文物名称，模糊查询 |
| `objectId` | String | 否 | 文物唯一标识 |
| `period` | String | 否 | 年代/时期 |
| `type` | String | 否 | 文物类型 |
| `material` | String | 否 | 材质 |
| `museum` | String | 否 | 所属博物馆 |
| `location` | String | 否 | 所在地区 |
| `auditStatus` | Integer | 否 | 数据状态：0 待审核，1 已发布，2 已下架 |
| `kgSyncStatus` | Integer | 否 | 知识图谱同步状态：0 未同步，1 已同步，2 同步失败 |

示例：

```text
GET /api/admin/artifacts/page?pageNum=1&pageSize=10&title=Bowl
```

### 8.2 查看文物详情

- 请求方式：`GET`
- 请求地址：`/api/admin/artifacts/{id}`

路径参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `id` | Long | 文物数据库 ID |

### 8.3 新增文物

- 请求方式：`POST`
- 请求地址：`/api/admin/artifacts`

请求体：

    "objectId": "import_001",

## 16. 常用接口测试顺序

验收或自测时建议按以下顺序测试：

1. 启动 MySQL，导入 `sql/init.sql`。
2. 启动后端服务，确认 8080 端口正常。
3. 调用 `/api/admin/auth/login`，使用 `admin / 123456` 登录。
4. 调用 `/api/admin/dashboard/summary`，确认看板统计正常。
5. 调用 `/api/admin/artifacts/page`，确认文物列表正常。
6. 新增一条文物，再修改、删除该文物。
7. 调用 `/api/admin/platform-users/page`，测试用户禁用、禁评、禁传。
8. 调用 `/api/admin/roles/{roleId}/permissions`，确认角色权限明细正常展示。
9. 调用 `/api/admin/content/audit/page`，测试通过、拒绝、复审。
10. 调用 `/api/admin/logs/login/page`，确认登录日志已生成。
