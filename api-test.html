🚀 后台管理系统 API 测试工具

登录认证
管理员管理
角色权限
查询接口
POST 1. 管理员登录
/api/admin/auth/login
GET 2. 当前登录用户信息
/api/admin/auth/profile
GET 3. 管理员列表查询
/api/admin/admin-users/page?pageNum=1&pageSize=10
POST 4. 管理员新增
/api/admin/admin-users
1=超级管理员, 2=内容审核员, 3=数据管理员
PUT 5. 管理员编辑
/api/admin/admin-users/{id}
PUT 6. 管理员启用/禁用
/api/admin/admin-users/{id}/status
GET 7. 角色列表查询
/api/admin/roles
GET 8. 权限列表查询
/api/admin/permissions
PUT 9. 角色权限分配
/api/admin/roles/{roleId}/permissions
1=超级管理员, 2=内容审核员, 3=数据管理员
多个权限ID用逗号分隔，会覆盖该角色原有权限
