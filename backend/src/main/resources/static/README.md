# 后台管理子系统前端

这是用于课程验收展示的后台管理子系统前端，直接调用现有 Spring Boot 后端接口。

## 启动方式

1. 启动 MySQL，确认 `admin_management_system` 数据库可用。
2. 启动后端，默认地址为 `http://localhost:8080`。
3. 在 `frontend` 目录启动静态服务：

```bash
python -m http.server 5173 --bind 127.0.0.1
```

4. 浏览器访问：

```text
http://127.0.0.1:5173/index.html
```

默认管理员账号：

```text
admin / 123456
```

## 功能模块

- 独立管理员登录页
- 看板总览
- 文物数据管理：查询、新增、编辑、删除、详情查看
- 平台用户管理：查询、启用/禁用、禁评/允许评论、禁上传/允许上传、查看用户内容
- 管理员管理：查询、新增、编辑、启用/禁用
- 角色权限管理：角色列表、权限勾选分配
- 内容审核：查询、通过、拒绝、复审、删除
- 敏感词库：查询、新增、编辑、删除
- 日志与备份：登录日志查询、手动创建备份记录

说明：平台普通用户、角色新增删除等功能目前后端未提供对应接口，前端未伪造这些操作。
